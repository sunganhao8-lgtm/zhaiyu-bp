## 1688 抓取技术备注(避免下次踩)
- 1688 s.1688.com 搜索页 URL 中文字符 → 服务端 GBK 解码 → 乱码,搜不到任何结果
  解决:用 `/kq/-XXX.html?beginPage=N` 类目聚合页(GBK 已经过浏览器内部编码转换)
- 1688 m.1688.com 跳转 taobao error 页(风控)
- 1688 详情页可以用未登录态抓,但短时间内访问太多会触发验证码拦截(每页间隔 6-15s)
- 1688 类目聚合页稳定出 20 个 offer/页,适合批量收集;搜索关键词页 JS 渲染拿不到
- 1688 详情页 offer id 必须是 13 位数字,部分老 id 已下架,需实测
- ⚠ SKU 字段"宠物用品款式"="非吊臂式" = 手持式(不是真挂脖/吊臂)
- ⚠ 部分 offer price 字段是模板基础价(¥100.00),实际 SKU 价格需 JS 渲染或人工核
